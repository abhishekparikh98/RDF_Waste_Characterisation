## 1. Project Summary

This is an MSc Computing dissertation project that builds a multi-modal machine learning pipeline to characterise waste and predict its suitability as **Refuse-Derived Fuel (RDF)**. The system combines a computer-vision image classifier (CNN / MobileNetV2 / ResNet50) with a tabular Random Forest model that maps the predicted waste class to RDF-relevant material features (moisture, contamination, combustibility, calorific value) and outputs a binary RDF-suitability decision with a probability score.

**Core workflow:**
`Image → Waste Classification (CNN) → Predicted Class → Material Feature Mapping → Random Forest → RDF Suitable / Not Suitable`

The repository contains the full research codebase, trained model artefacts, evaluation reports, plots, a Flask demo application, and a command-line multimodal inference script. A TACO dataset submodule is present but was not used in the modelling pipeline — only TrashNet was used for training.
