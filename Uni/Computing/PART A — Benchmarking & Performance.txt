PART A — Benchmarking & Performance Analysis

This part is about checking device performance, comparing them, showing graphs, and making decisions.

1. Benchmark your own laptop

Install Novabench → run test → save the results.

You will get numbers for:

CPU score

RAM score

GPU score

Disk read/write speed

These numbers become your “reference”.

2. Research specs for all listed devices

For each device:

CPU model + performance score (Geekbench/Novabench scores)

RAM: size & speed

GPU: integrated or dedicated

Storage speed: SSD/HDD (MB/s)

You can use official sites, reviews, or benchmark databases.

Devices to research:

Lenovo Yoga 7

ASUS ZenBook Duo

MacBook Pro

MSI 9th Gen

HP Envy 7th Gen

Lenovo Ideapad

ASUS ZenBook 14 (x2)

HP Envy 11th Gen

Microsoft Surface Pro

3. Simulate a CPU task

Example:

Task requires 1 million cycles

Use CPU frequency to estimate execution time
Formula (simple):

Time = cycles / CPU clock speed


You show:

Fastest device

Slowest device

How performance changes

4. Create graphs

At least:

CPU comparison bar graph

RAM size comparison

Disk speed comparison

(Make them clean and readable.)

5. Decision Making

Write which devices the clinic should keep or replace, based on:

Slow CPU

Low RAM

Old generation

Poor disk speed

Then recommend new devices (example: Dell OptiPlex, Mac Mini, Lenovo ThinkPad).
